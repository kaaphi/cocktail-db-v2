# Cocktail DB

This is a website containing cocktail recipes.

The source-of-truth for recipes is in [cocktail-data/data](cocktail-data/data). These are YAML files that are designed to be easy for a human to write using a mix of block style and flow style.
The cocktail-data module has a Python script that will compile these YAML files into a JSON object in the cocktail-ui module.

The cocktail-ui module is a React SPA with no backend. All the cocktail data is included in the UI build via the JSON object generated by cocktail-data.
